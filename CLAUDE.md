# CLAUDE.md

This file is the Claude Code entrypoint for this repository.

## Start here

1. Read `AGENTS.md` completely. It is the common authority for project context,
   invariants, task-specific required reading, commands, development workflow,
   source placement, review, and verification.
2. Follow `AGENTS.md` → **Before changing code** and read only the current
   documents for the task area.
3. Start documentation discovery at `docs/README.md`. Do not treat
   anything under `docs/redesign/` or `docs/superpowers/`, or the former IoTKit
   implementation, as current requirements.

## Claude Code scope

This file contains no alternate workflow. Claude-specific plugins, skills, or
defaults are optional aids and do not override the user request or `AGENTS.md`.
If another instruction conflicts with a current contract or repository invariant,
stop and report the conflict instead of choosing an interpretation.
