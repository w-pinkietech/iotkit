# Glossary

See also: `iotkit-reverse-extracted/README.md` glossary section for Node-RED, hardware, architecture, and Japanese system label definitions.

| Term | Definition |
|------|-----------|
| IoTKit | The overall Raspberry Pi-based IoT gateway system |
| BravePI | Serial-connected wireless BLE sensor receiver |
| BraveJIG | USB serial-connected device management gateway |
| flows.json | Node-RED flow definition file (legacy runtime core) |
| iotkit-reverse-extracted | Reverse-engineered reference repository with requirements and design docs |
| iotkit-next | Target repository for the new implementation |
